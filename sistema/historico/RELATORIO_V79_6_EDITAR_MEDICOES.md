# V79.6 — Editar medições

## Regra
- O botão **Editar** aparece em cada registro do histórico.
- Ao editar, o Memory carrega data, observação e todos os campos daquela medição.
- **Salvar alterações** substitui o registro original usando o mesmo ID.
- A edição não cria uma nova linha e não duplica o histórico.
- **Cancelar edição** abandona as alterações locais.
- Continua incluída a V79.5: decimal com vírgula/ponto no celular e Body Scan comparativo.
