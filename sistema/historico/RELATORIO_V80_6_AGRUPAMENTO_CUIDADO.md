# V80.6 — Agrupamento do Cuidado

O problema era que o item **Cuidado** havia virado apenas um link para o Mapa.
Visualmente os itens estavam indentados, mas não existia mais um controle independente
para recolher/expandir o grupo.

## Novo comportamento
- Clique no nome **Cuidado** → abre o Mapa de Cuidado.
- Clique na **seta** → recolhe/expande os itens.
- Em páginas de Cuidado o grupo abre automaticamente.
- O estado também fica salvo localmente.
- No mobile, a seta abre a lista de itens em uma folha/modal.
