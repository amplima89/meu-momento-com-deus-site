# Auditoria visual de exercícios — V79

Data: 15/08/2026

## Objetivo
Conferir a coerência entre nome, orientação e mídia dos exercícios usados pelo módulo de Treinos, corrigindo referências que pudessem induzir a uma execução diferente da prescrita.

## Resultado
- Os IDs de guia explicitamente usados pelo plano-base foram conferidos e todos possuem entrada no catálogo visual V79.
- **Leg Press unilateral** foi corrigido: deixou de reutilizar as fotos do Leg Press bilateral e passou a usar ilustração própria, com texto que reforça que somente uma perna empurra a plataforma.
- **Leg Press bilateral** e o finisher bilateral continuam usando a referência bilateral correta; a correção unilateral não contamina esses exercícios.
- Referências de base que mostram uma variação diferente do aparelho/posição — por exemplo Avanço Reverso no Smith, Puxada Alta Ajoelhado e Elevação Lateral no crossover — permanecem explicitamente identificadas no próprio guia como **referência de padrão de movimento**, com a diferença descrita ao usuário. Elas não são apresentadas como demonstrações idênticas.
- O catálogo V79 preserva a fonte de cada mídia e exibe observação específica sempre que a imagem é apenas uma referência mecânica.

## Regra para próximas inclusões
Um exercício novo não deve receber uma mídia de outro movimento como se fosse equivalente. Quando não houver demonstração exata, o Memory deve usar uma ilustração própria ou declarar claramente que a mídia é apenas referência de trajetória/mecânica.
